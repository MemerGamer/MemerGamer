## Kovács Bálint-Hunor

Full-stack developer and PhD student at the University of Debrecen (Doctoral School of Informatics).
I build web products for clients and research how to make software delivery verifiable.

**Research.** Cryptographically verifiable DevSecOps: build provenance, signing, attestations,
transparency logs and reproducible builds, measured on real CI/CD pipelines.
My MSc work at Sapientia is [devsecops-attestation](https://github.com/MemerGamer/devsecops-attestation),
which records CI/CD security decisions as cryptographically verifiable evidence.

**Engineering.** TypeScript and React on the front end; Node/Bun, Go, Rust and PostgreSQL behind it.
I run my own infrastructure (Forgejo, CI runners, Prometheus/Loki/Grafana, game servers),
provisioned with Ansible and updated automatically with rollback.
